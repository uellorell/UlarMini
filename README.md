# Ular Neon

Game ular arena berbasis Canvas, dibuat dengan HTML, CSS, dan JavaScript tanpa dependensi. Tampilan terinspirasi dari dua gambar referensi yang diberikan pengguna.

## Menjalankan secara lokal

Buka `index.html` di browser, atau jalankan server statis dari folder ini:

```sh
python3 -m http.server 4173
```

Lalu buka `http://localhost:4173`.

## Cara bermain

- Arahkan ular dengan mouse, tombol panah, WASD, sentuhan di arena, atau joystick virtual.
- Tahan **Space** atau tombol petir untuk boost. Boost mengurangi panjang ular.
- Makan orb untuk mendapat skor dan tumbuh. Hindari batu, tepi arena, badan ular sendiri, dan ular lain.
- Tekan **P** atau tombol jeda untuk berhenti sementara.

Papan peringkat menampilkan bot lokal. Skor terbaik pribadi tersimpan di browser.
